# Family Counter Hub

iPad-friendly family dashboard for the kitchen counter.

## Features
- Live clock & date
- Weather (Open-Meteo, location or city)
- Word of the Day & Fact of the Day
- To-Do List with voice input (Web Speech API)
- Grocery List with voice
- Chore Chart (checkboxes, weekly reset)
- Recipes list
- Calendar sync via Google Calendar secret ICS URLs (you + wife)
- Sports scores (NFL, NBA, MLB via ESPN)
- PWA: Add to Home Screen for full-screen kiosk mode

## Setup
1. Enable GitHub Pages in repo settings (branch: main, folder: / (root))
2. Open the Pages URL on your iPad
3. Add to Home Screen
4. In Google Calendar settings > Integrate calendar, copy the **Secret address in iCal format** for each calendar and paste into the app
5. Set city or allow location for weather
6. Mount the iPad!

Data is stored in localStorage on the device. Perfect for a shared counter tablet.

Voice example: Tap 🎤 and say "call David about getting a tire change" — it adds to the to-do list.

Enjoy!
